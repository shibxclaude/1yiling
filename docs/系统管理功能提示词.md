# 后台管理系统代码生成提示词

> 使用方式：将本文档全文作为 Prompt 发给 AI 编程助手，即可生成一套与本系统（paxl-manager）同等功能的通用后台管理系统。
> 适用模型场景：Claude / CodeBuddy / Cursor 等 AI 代码生成工具。

---

## 一、角色与目标

你是一名资深前后端全栈工程师，请根据本提示词中的**功能清单与技术约束**，生成一套完整的、可运行的企业级通用后台管理系统（前端 + 后端 + 数据库脚本）。系统为典型的 RBAC 权限管理系统，包含用户、角色、菜单、部门、岗位、字典、参数、通知公告、操作日志九大模块。

## 四、全局公共约定（必须遵守）

1. **响应包装**：所有接口统一返回 `{ code, message, data }`；成功 code=200。
2. **分页**：入参 `{ pageNo, pageSize }`（默认 1/10），返回 data 为分页对象 `{ records, total, size, current, pages }`。
3. **查询接口均为 POST + JSON Body**（非 RESTful GET 参数风格），路径规范：`rest/{实体名}/{动作}`：
   - `POST rest/xxx/listPage` 分页、`POST rest/xxx/list` 不分页列表、`POST rest/xxx/detailById` 详情、
     `POST rest/xxx/save` 新增、`POST rest/xxx/update` 修改、`POST rest/xxx/delete` 删除、`POST rest/xxx/updateSimple` 局部更新。
4. **登录认证**：`POST /login` 入参 `{ username, passwd }` 返回 `{ token }`；`GET /getInfo` 返回 `{ user, roles[], permissions[] }`；`GET /getRouters` 返回动态菜单路由树。
5. **时间格式**：全局序列化/反序列化统一 `yyyy-MM-dd HH:mm:ss`；同时兼容 ISO-8601 输入（如 `2024-12-24T20:24:46.000+08:00`）。
6. **状态字段**：业务表统一 `status`（0=删除 1=正常 2=停用，详见各模块注释）。
7. **权限标识**：按钮级权限使用 `v-hasPermi="['system:user:add']"` 指令；标识规则 `system:{模块}:{动作}`。
8. **列表页统一三段式布局**：搜索表单区（inline，右上角可由 RightToolbar 折叠/展开）→ 操作按钮工具栏（新增/修改/删除/导出等，下方 el-row.mb8 右侧挂 RightToolbar）→ 表格 + 分页。
9. **删除交互**：单条删除行内文字按钮；批量删除顶部按钮（依赖多选）；均需 `$modal.confirm` 二次确认。
10. **导出**：调用后端 Excel 导出接口，axios 以 `responseType: 'blob'` 下载，从 Content-Disposition 解析文件名。
11. 数据库表名：系统表“sys_”开头，业务表"t_"开头，字典表“c_"

## 五、模块功能清单（共 9 大模块 / 18 个页面）

### 模块 1：用户管理（views/system/user/index.vue）

**功能点**
- 用户列表分页查询：筛选条件 = 归属部门（el-tree-select 部门树）、用户名称、手机号码、状态（正常/停用）
- 新增用户（弹窗表单）：昵称*、归属部门*（树选择）、手机号、邮箱、用户名称*（仅新增可改）、密码*（仅新增）、性别（sys_user_sex 字典）、状态、岗位（多选）、角色（多选）、备注
- 修改用户（回显，密码不可改）、删除（行内单个 + 批量）
- 状态切换（el-switch 正常/停用）
- 重置密码（prompt 输入新密码，校验 5-20 位）
- 导出用户 Excel；导入用户（上传 Excel）【可选】
- 「更多操作」下拉：重置密码 / 分配角色（跳转子页 authRole）

**表格列**：编号、用户名称、用户昵称、部门、手机号码、状态(switch)、创建时间、操作

**关联子页面**
- `user/authRole.vue`（分配角色）：左侧展示用户信息卡，右侧角色列表勾选后保存授权

**接口清单**
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | rest/sysUser/listPage | 分页列表（入参 SysUserDto：deptId/username/phone/status/pageNo/pageSize） |
| POST | rest/sysUser/list | 不分页列表 |
| POST | rest/sysUser/detailById | 详情（返回 user 含 roles/posts 关联对象） |
| POST | rest/sysUser/save | 新增（必填 username/nickName/passwd/deptId；携带 roleIds/postIds 数组） |
| POST | rest/sysUser/update | 修改（passwd 置空不修改） |
| POST | rest/sysUser/updateSimple | 局部更新（id/status，状态切换用） |
| POST | rest/sysUser/delete | 删除（id） |
| POST | rest/sysUser/resetPwd | 重置密码（id/passwd） |
| POST | rest/sysUser/profile | 当前登录人信息 |
| POST | rest/sysUser/updateSelfSimple | 个人中心改资料（nickName/email/phone 必填） |
| POST | rest/sysUser/updatePwd | 修改密码（oldPassword/newPassword） |
| POST | rest/sysUser/avatar | 头像上传（multipart/form-data，返回访问地址） |

### 模块 2：角色管理（views/system/role/index.vue）

**功能点**
- 分页查询：角色名称、权限字符、状态筛选
- 新增/修改（弹窗）：角色名称*、权限字符*、显示顺序*、状态、菜单权限树（el-tree 多选：展开/折叠/全选/父子联动 menuCheckStrictly）、备注
- 删除（保护超管角色不可删）、状态切换
- 分配数据权限（弹窗：数据范围 radio 五种 = 1全部/2自定义/3本部门/4本部门及以下/5仅本人；自定义时展示部门树勾选 deptIdList）
- 分配用户（跳转 role/authUser.vue 子页）
- 导出 Excel

**表格列**：角色编号、角色名称、权限字符、显示顺序、状态(switch)、创建时间、操作（修改/数据权限/分配用户/删除 下拉或平铺）

**子页面**：`role/authUser.vue` + `role/selectUser.vue`（授权用户取消/批量取消、未授权用户批量添加）

**接口清单**
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | rest/sysRole/listPage、list、detailById、save、update、delete、updateSimple | 标准 CRUD 集 |
| POST | rest/sysMenu/treeSelect | 菜单树下拉 |
| POST | rest/sysMenu/roleMenuTreeSelect | 入参 roleId，返回 `{ checkedKeys:[], menus:[TreeSelect] }` |
| POST | rest/dataPerm/dataScope | 保存数据权限（id/dataScope/deptIdList） |
| POST | rest/dataPerm/deptTreeByRole | 入参 roleId，返回 `{ checkedKeys:[], depts:[TreeSelect] }` |
| POST | rest/sysDept/deptTree | 全量部门树 |

**数据库**：`sys_role`（id/role_name/role_key/data_scope/dept_ids/menu_check_strictly/dept_check_strictly/status/remark…，role_key 唯一索引）、`sys_role_menu`(role_id/menu_id)、`sys_user_role`(user_id/role_id)

### 模块 3：菜单管理（views/system/menu/index.vue）

**功能点**
- 树形表格展示（不分页）：菜单名称、状态筛选；展开/折叠全部
- 新增/修改（弹窗）：上级菜单（树选择，可在行内“新增下级”预置 parentId）、菜单类型 radio（0目录/1菜单/2按钮）、图标选择器 IconSelect、名称*、排序*、是否外链 ifFrame、路由地址 path、组件路径 component（仅菜单）、权限字符 perms（非目录必填）、路由参数 query、是否缓存 keepAlive、显示状态
- 删除（有子节点时禁止）
- 新增/编辑时按类型动态显隐字段

**表格列**：菜单名称(带图标)、图标、排序、权限标识、组件路径、状态(tag)、创建时间、操作（修改/新增下级/删除）

**数据库**：`sys_menu`（parent_id/menu_name/menu_type/menu_sort/menu_path/menu_component/perms/if_frame/if_cache/status…；path/perms/component 唯一索引）；初始数据：系统管理目录 + 九大页面菜单 + 各模块按钮权限

### 模块 4：部门管理（views/system/dept/index.vue）

**功能点**
- 树形表格展示：部门名称、状态筛选；展开/折叠
- 新增/修改（弹窗）：上级部门*（树选择，行内可“新增下级”）、部门名称*、显示顺序*、负责人、联系电话、邮箱、状态
- 删除（顶级/有子部门禁删）

**数据库**：`sys_dept`（parent_id/ancestors 祖级列表/dept_code 唯一/dept_name/order_num/leader/phone/email/status）

### 模块 5：字典管理（views/system/dict/index.vue + dict/data.vue）

**功能点**
- 类型页：分页查询（字典名称、类型、状态）；新增/修改（名称*、类型*、状态、备注）；点击“字典数据”携 dictType 跳转数据页；导出
- 数据页：按 dictType 分页查询（标签、状态筛选）；新增/修改（标签*、键值*、排序*、样式属性 cssClass、回显样式 listClass、是否默认、状态、备注）；删除支持批量；导出
- 前端提供 `useDict(...types)` 组合函数 + `<dict-tag>` 组件渲染枚举值

**数据库**：`sys_dict_data`（dict_type/dict_label/dict_value/dict_sort/css_class/list_class/is_default/remark/status）；预置字典：sys_normal_disable、sys_user_sex、sys_show_hide、sys_yes_no、sys_notice_type、sys_notice_status、sys_oper_type

### 模块 6：参数配置（views/system/config/index.vue）

**功能点**：分页查询（参数名称、键名、内置、创建时间范围）；新增/修改（名称*、键名*、键值*、是否内置 y/n、备注）；删除批量；导出；刷新缓存按钮

**数据库**：`sys_config`（config_name/config_key 唯一/config_value/config_type/remark）

### 模块 7：通知公告（views/system/notice/index.vue）

**功能点**：分页查询（标题、创建者、类型）；新增/修改（标题*、类型*通知/公告、状态、富文本内容* Editor 组件）；删除批量

**数据库**：`sys_notice`（notice_title/notice_type/notice_content longtext/notice_param/status）

### 模块 8：岗位管理（views/system/post/index.vue）

**功能点**：分页查询（岗位编码、岗位名称、状态）；新增/修改（编码*、名称*、顺序*、状态、备注）；删除批量；导出

**数据库**：`sys_post`（post_code 唯一/post_name/post_sort/remark/status）

### 模块 9：操作日志（views/system/sysLog/index.vue）

**功能点**
- 分页查询：操作人员、业务类型下拉（0其他/1新增/2修改/3删除）、操作 IP
- 详细查看（抽屉/描述列表展示全部字段）
- 删除批量；导出 Excel（仅超管可删）

**表格列**：日志编号、系统模块(title)、业务类型(tag)、操作人员(operName)、主机地址(operIp)、操作状态(tag 成功/失败)、操作时间(operTime)、消耗时间、操作

**数据库**：`sys_oper_log`（title/business_type/method/request_method/operator_type/oper_id/oper_name/dept_id/dept_name/oper_url/oper_ip/oper_location/oper_param/json_result/status/error_msg/oper_time/cost_time；后端 AOP @Log 注解自动记录）

### 个人中心（views/system/user/profile/*）

- profile/index.vue：左右布局——左卡（头像大图 + 用户名/手机/邮箱/部门/岗位/角色/创建日期），右 tab 页（个人信息 userInfo / 修改密码 resetPwd）
- userInfo.vue：昵称*、手机号*、邮箱*、性别
- resetPwd.vue：旧密码*、新密码*(5-20位)、确认密码*（一致性校验）
- userAvatar.vue：cropperjs 裁剪 + multipart 上传实时更新

## 六、布局框架要求

- Layout：固定左侧深色菜单（logo + el-menu 动态渲染，折叠收起）、顶部导航栏（面包屑 + 搜索 + 全屏 screenfull + 尺寸切换 + 用户下拉[个人中心/退出登录]）、主区域 router-view + TabsView 标签页缓存(keep-alive) + 设置面板（主题色/侧边栏配色开关，可选）
- 首页 Dashboard：简单欢迎卡片即可

## 七、数据库初始化交付物

1. 所有表的 MySQL DDL（InnoDB utf8mb4，带注释与唯一/普通索引）
2. 初始数据：admin 超管账号(BCrypt 密码)、超管角色 super_admin、dept 总公司、常用 sys_dict_data、sys_config 示例
3. `sys_menu` 菜单与按钮权限 INSERT 脚本（目录→菜单→按钮三级，perms 与 v-hasPermi 一一对应）
4. 角色-菜单初始绑定关系

## 八、质量验收标准

1. 前端启动无报错，九大模块页面可走通：查询→新增→编辑→删除→分页
2. 所有 CRUD 均有 loading 遮罩、表单必填校验、删除二次确认、成功/失败 toast
3. 无 unused import；组件命名 PascalCase；请求方法按模块拆分至 api/system/*.js
4. 按钮权限符合 v-hasPermi 配置；未登录跳转 /login；动态路由按 getRouters 渲染
5. 时间列展示均为 yyyy-MM-dd HH:mm:ss
